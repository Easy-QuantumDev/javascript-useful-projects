# 🚀 JavaScript Useful Projects

A collection of mini projects built with JavaScript to practice and improve programming skills.

This repository is focused on creating small and useful JavaScript projects to understand core concepts, improve problem-solving abilities, and gain practical experience in frontend development.

Through these projects, different JavaScript concepts such as DOM manipulation, events, functions, logic building, and interaction with web pages are practiced.

The main goal of this repository is learning by building real examples and improving JavaScript skills step by step.
